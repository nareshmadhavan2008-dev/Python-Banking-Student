# Python Banking System

## Project Overview
A simple Banking System developed using Python
and Object-Oriented Programming (OOP).

## Features
- Account Creation
- Savings and Current Accounts
- Deposit Money
- Withdraw Money
- Check Balance
- Transaction History

## OOP Concepts
- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Technologies Used
- Python 3

## How to Run
1. Open the project in VS Code.
2. Open Terminal.
3. Run:

   python main.py

## Project Files
- bank.py
- main.py
- class_diagram.md
- README.md

## Project Purpose
To learn and implement Object-Oriented Programming
concepts through a simple Banking System.
